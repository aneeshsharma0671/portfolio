# Agent Reports

Use this directory for durable handoffs between Claude, Codex, and child agents.

Recommended files:

- `*-plan.md` for implementation plans.
- `*-review.md` for code review findings.
- `*-research.md` for docs or design research.
- `*-verification.md` for build, lint, test, or browser-check results.

Keep reports concise and include exact commands, file paths, and unresolved questions.
